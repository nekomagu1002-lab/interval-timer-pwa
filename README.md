# 筋トレ支援PWA

家にある器具と最近のトレーニング記録をもとに、その日の筋トレメニューを端末内で提案し、セット記録まで完結できる個人用PWAです。生成AI、外部API、アカウント、クラウド同期は使用しません。

バージョン: **v1.0.0**

公開先: [GitHub Pages](https://nekomagu1002-lab.github.io/interval-timer-pwa/)

## 主な機能

- 「軽め」「普通」「ガッツリ」から今日の運動量を選択
- 有効な器具、最近使った部位・種目、直近の記録を考慮したルールベースのメニュー生成
- 基本種目を残しつつ、候補の一部を入れ替える安定したメニュー構成
- メニュー全体の再生成と、種目単位の入れ替え
- 重量・回数・時間・セット完了をスマートフォンで素早く記録
- トレーニング中に各種目の直近3回、種目画面で直近5回の記録を確認
- セット完了後の休憩タイマーと、時間系種目の計測タイマー
- 従来のHIIT用インターバルタイマーを独立機能として統合
- 器具の追加・削除・有効化、種目の追加・削除・有効化
- トレーニング履歴の端末内保存
- JSON形式の一括バックアップと復元
- Web Audio APIによる音量・音色設定
- Screen Wake Lock対応と、Service Workerによるオフライン起動

## 使い方

1. 初回は「器具」で手元にある器具だけをONにします。
2. HOMEで「軽め」「普通」「ガッツリ」のいずれかを選びます。
3. 提案されたメニューを確認します。必要なら個別の「入替」または「全体を再生成」を使います。
4. 「このメニューで開始」を押します。
5. 重量・回数を調整し、「セット完了」を押します。最終セット以外は種目の標準休憩タイマーが始まります。
6. すべて終えたら「記録を保存して終了」を押します。

トレーニング途中の状態はIndexedDBへ保存されるため、誤って再読み込みした場合も再開できます。ただし、端末やSafariのデータを削除すると記録も消えるため、定期的なJSONエクスポートを推奨します。

## メニュー生成の考え方

メニュー生成は完全なランダムではありません。

- 選択した強度に応じて種目数・セット数・目安時間を調整
- OFFの器具を必要とする種目は候補から除外
- 直近のトレーニングで負荷が集中した部位を少し休ませる
- 同一部位や同一種目の連続を避ける
- `foundation`が設定された基本種目を優先し、継続性を保つ
- 同条件で候補が複数ある場合だけ一部を入れ替える
- 直近の完了記録から重量と平均回数を初期値として提案

このロジックは`js/generator.js`、種目マスターは`js/data.js`に分離しています。運動科学上の個別診断ではなく、日々の選択を短くするための補助機能です。体調や痛みに応じて自分で負荷を調整してください。

## 画面

- **HOME**: 今日の強度選択、進行中トレーニング、最近の傾向
- **今日**: 提案メニューの確認・入れ替え・開始
- **実行**: セット記録、前回記録、セット間休憩
- **履歴**: 保存済みトレーニングの一覧と内容
- **種目**: 種目マスターの確認・追加・有効化
- **器具**: 使用可能な器具の追加・有効化
- **タイマー**: HIITなどに使う従来型インターバルタイマー
- **設定**: 通知音、JSONバックアップ、アプリ情報

## 保存データ

IndexedDBデータベース`myTrainingPwa`に次のストアを作成します。

| ストア | 内容 |
| --- | --- |
| `settings` | 音量、音色、インターバルタイマー設定 |
| `equipment` | 器具名、有効状態、組み込み判定 |
| `exercises` | 種目名、部位、器具、回数/時間、標準値、対応強度 |
| `workouts` | 日時、強度、実施種目、重量、回数、時間、セット |
| `appState` | 提案中メニューと進行中トレーニング |

設定画面の「JSONを書き出す」は、上記データをひとつのファイルに保存します。「JSONから復元」は現在の端末内データを選択ファイルの内容で置き換えるため、先に現状をエクスポートしてください。

## インターバルタイマー

- 運動時間・休憩時間は5秒刻み、セット数は1回刻みで設定
- 開始、一時停止、再開、リセット
- 最後の運動セット終了後は休憩せず完了
- 開始、切り替え、残り3秒、完了をWeb Audio APIで通知
- 音量は消音・小・中・大、音色はビープ・アラーム・ベル
- `Date.now()`を基準に残り時間を再計算し、表示遅延によるずれを補正

## iPhoneでホーム画面に追加する

1. Safariで[公開URL](https://nekomagu1002-lab.github.io/interval-timer-pwa/)を開きます。
2. 共有ボタンを押します。
3. 「ホーム画面に追加」を選びます。
4. ホーム画面のアイコンから起動します。

通知音はiPhone本体のメディア音量や端末設定にも影響されます。Screen Wake Lock APIが利用できる場合は実行中の画面スリープを防ぎますが、バックグラウンドや画面ロック中の正確なタイマー動作は保証しません。基本的に画面を開いた状態で使用してください。

## GitHub Pagesで公開する

1. リポジトリの **Settings** → **Pages** を開きます。
2. Sourceに **Deploy from a branch** を選びます。
3. Branchに`main`、Folderに`/ (root)`を選び、保存します。
4. `https://nekomagu1002-lab.github.io/interval-timer-pwa/`へアクセスします。

HTML、manifest、Service Worker、キャッシュ対象はすべて相対パスです。GitHub Pagesのリポジトリ配下でもService Workerのスコープが閉じる構成です。更新時は`sw.js`のキャッシュ名も変更してください。

## ローカルで確認する

Service WorkerとWake Lockは安全なコンテキストが必要です。ファイルを直接開かず、プロジェクトルートでローカルHTTPサーバーを起動します。

```powershell
python -m http.server 4173
```

その後、`http://localhost:4173/`を開きます。
