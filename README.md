# Interval Timer PWA

筋トレ、ストレッチ、HIITなどに使える、スマートフォン向けのシンプルなインターバルタイマーです。  
フレームワークや外部音声ファイルを使わず、HTML / CSS / JavaScriptだけで構成しています。

バージョン: **v0.2.0**

## 公開URL

https://nekomagu1002-lab.github.io/interval-timer-pwa/

## 主な機能

- 運動時間・休憩時間を5秒刻みで設定
- セット数を1〜99回で設定
- 開始、一時停止、再開、リセット
- 運動・休憩・完了の状態表示
- 最終セット終了後は休憩を挟まず完了
- 開始・切り替え・残り3秒・完了時の通知音
- 4段階の音量と3種類の音色、試聴機能
- 前回設定の自動保存
- Service Workerによる基本画面のオフライン利用
- タイマー実行中のScreen Wake Lockによる画面スリープ防止

## 使い方

1. 運動、休憩、セットの「−」「＋」ボタンで設定します。
2. 「開始」を押すと運動タイマーが始まります。
3. 必要に応じて「一時停止」「再開」を使います。
4. 「リセット」を押すと待機状態に戻ります。

音声はWeb Audio APIで生成します。iPhone Safariの仕様に合わせ、最初に「開始」または「再開」を押したユーザー操作をきっかけに音声を有効化します。

対応環境では、タイマー実行中と一時停止中にScreen Wake Lock APIを使って画面の自動スリープを防止します。画面切り替え後にアプリへ戻った場合はWake Lockを再取得します。

> Screen Wake Lock APIにはHTTPS環境が必要です。GitHub PagesはHTTPSに対応しています。API非対応や取得失敗時もタイマーは動作しますが、バックグラウンド動作中や端末のスリープ中に正確な動作は保証されません。画面を開いた状態で利用してください。

## iPhoneでの使い方

1. Safariで公開URLを開きます。
2. 共有ボタンを押します。
3. 「ホーム画面に追加」を選びます。
4. ホーム画面のアイコンから起動します。

## 注意事項

- 通知音の音量はiPhone本体のメディア音量にも影響されます。
- 消音モードや端末設定により挙動が変わる可能性があります。
- バックグラウンドや画面ロック中の正確な動作は保証しません。
- 画面を開いた状態で使用してください。

## localStorageで保存する内容

キー名: `intervalTimerSettings`

```json
{
  "workSeconds": 30,
  "restSeconds": 60,
  "sets": 3,
  "volume": "medium",
  "tone": "beep"
}
```

保存するのは運動時間、休憩時間、セット数、音量、音色です。タイマーの進行状態や運動履歴は保存しません。

音量は`mute`（消音）、`small`（小）、`medium`（中）、`large`（大）、音色は`beep`（ビープ）、`alarm`（アラーム）、`bell`（ベル）のいずれかです。実際の音量は端末本体のメディア音量にも依存します。

## 実装メモ

- 状態は`js/app.js`内の単純なJavaScriptオブジェクトで管理しています。
- 残り時間は`Date.now()`と終了予定時刻との差から計算し、`setInterval`の遅延によるズレを抑えています。
- 音はWeb Audio APIのOscillatorで生成しています。
- オフライン用キャッシュを更新する場合は、`sw.js`の`CACHE_NAME`を変更してください。
